# fridge

냉장고에 넣어둔 재료와 유통기한을 기록하는 아이폰 홈 화면용 웹앱(PWA).

- 기한 지남 / 임박 / 여유로 나눠서 유통기한 빠른 순으로 보여줌
- 냉장·냉동·실온 탭, 검색
- 자주 사는 재료를 누르면 이름·아이콘·보관 장소·유통기한이 자동으로 채워짐
- 다 먹음 / 버림 처리 (되돌리기 가능), 이번 달 통계
- 데이터는 폰에만 저장됨 → 설정에서 백업 저장/불러오기

주소: https://iiacyp4-wq.github.io/Fridge/
사파리로 열고 공유 → "홈 화면에 추가".

아이콘 다시 만들기: `python tools/make_icons.py`
